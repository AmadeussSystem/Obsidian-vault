# Machine Learning 

### What is Machine Learning?
-  Machine Learning is the field of study that gives computers the ability to learn without being explicitly programmed.
### Can you name four types of applications where it shines?
- Analyzing images of products on a production line to automatically classify them 
- Automatically Classifying news articles.
- Detecting Tumors in brain scans.
- Forecasting companies revenue next year, based on many performance matrices.
### Types of Machine Learning Systems
 #### Based on Training supervision
 - **Supervised Learning** - the training set you feed to the algorithm includes the desired solutions, called labels. Typically used in classification jobs.    
![[2-202512271853.png]] 
![[3-202512271853.png]]

- **Unsupervised Learning** -the training data is unlabeled. The system tries to learn without a teacher. A typical task is classification example (spam vs ham). 
![[4-202512271853.png]]
- **Semi-supervised Learning** - Since labeling data is usually time consuming and costly , you will have plenty of unlabeled instances, and few labeled instances. Some algorithms can deal with data that's partially labeled.
![[5-202512271853.png]]
- **Self Supervised** - another approach to machine learning involves actually generating a fully labeled data set from a fully unlabeled one. Again, once the whole data is labeled any supervised learning algorithm can be used. This approach is called Self supervised Learning.

![[6-202512271853.png]]
- **Reinforcement Learning** - The learning system, called an in this context, can observe the environment, select and perform actions, and get reward in return or penalties in the form of negative rewards. It must then learn by itself what is the best strategy, called a policy, to get the most reward over time. A policy defines what actions the agent should choose when it is in a given situation.

### Types of Machine Learning Systems

#### Batch Versus Online Learning 
 Another criterion used to classify machine learning systems is whether or not the system can learn incrementally from a stream of incoming data.
 - Batch Learning - In batch Learning, the system is  incapable incrementally it must be trained using all the available data. This will generally take a lot of time and computing resources, so it is typically done offline. First the system is trained, and then it is launched into production and runs without learning anymore; it just applies what is has learned. This is called offline learning. Unfortunately, a model's performance tends to decay slower over time, simply because the world continues to evolves while the model remain unchanged. This phenomenon is often called Data rot or data drift. The solution is to regularly retrain the model on up-to-data Data.
 - Online Learning - In online learning you train the system  incrementally by feeding it data instances sequentially, either individually or in small groups called mini-batches Each learning step is fast and cheap so the system can learn new data on the fly, as it arrives.

### Main Challenges of Machine Learning
 In short since your main task is select a model and train it on some data, the things that can go wrong are "bad model" and "bad data". Lets start with examples of bad Data 
- Insufficient Quantity of Training Data 
- Nonrepresentative Training Data - **In order to generalize well, it is crucial that your training data be representative of the new cases you want to generalize to, This can result in having *sampling noise* (when the sample size is to small) or *sampling bias*(when there is a selection bias in the samples) **
- Poor Quality Data - **if some instances are clearly outliers, it may help to simply discard them or try to fix the errors manually or some instances are missing a few features you must decide whether you want to ignore this attribute altogether, ignore these instances, fill in the missing values or train one model with the feature and one model without without it.**
